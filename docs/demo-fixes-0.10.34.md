## 建议实机复测顺序

1. **P0 停止权限**：让通道任务停止后输入上面的原句。应返回原因、已完成部分和最新库存，同伴原地等待；不得出现新竖井、新预览或新的挖掘。再单独下新目标时仍须按新预览确认。
2. **空置住房修补**：准备缺椅子、光源的空房，检测→预览→确认修补→再次检测。应不再报重复匹配；有人居住、位置被占、缺料时继续保留原有限制。
3. **埋矿通道**：先在普通草地／土壤上测近距离埋矿。确认前不挖；确认后允许正常草皮变化。再加入水或线路，应及时停止并保留准确进度。移除与入包应分别核验。
4. **连续种植**：相邻草地种3株太阳花，确认后应完成3/3；种植中插入障碍或改变土壤，则应停止而不覆盖现场。
5. **克眼准备**：分别缺生命水晶／水瓶、材料齐备时打开完整计划。缺料应列清且不可开工；齐备后确认才备料施工。更换库存或位置要刷新并重新确认。
6. **RAG**：问“克眼怎么召唤／自然生成”。应展示保留分组的条件摘录与来源；版本不匹配时不引用旧 Wiki。战斗建议不能冒充召唤门槛。
