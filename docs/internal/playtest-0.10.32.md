# 0.10.32 采矿回归（玩家实机验收）

本版已跑自动化验证，不代替实机验收。上一版水坑修复继续保留。

1. **只剩埋住的矿**：站在截图附近，下达“挖1处矿”。若矿全部被土石封住，应提示附近没有露出且镐力足够的目标；不应连试整条埋藏矿脉后报“规划步数上限”，也不应自动挖通道。
2. **有露头矿**：在附近露出一格能挖的矿，重发“挖1处矿”。同伴应靠近、移除指定矿格并核实进度；旁边无关方块应保留。掉落是否入包单独核对。
3. **道路仍不通**：让露头矿隔着不可通过的地形。不可达目标应被跳过；没有别的目标或达到本次尝试上限时，应说明最近一次移动失败，保留真实进度，不能声称成功。
4. **指定矿种但镐力不够**：请求当前镐无法挖的矿，应明确要求更好的镐，不反复尝试这些矿格。
5. **确认与停止**：开启采集需确认的偏好后重复第 2 项。确认前不能挖；确认只允许本次目标。确认前或执行中停止后，不能继续选择并挖下一个目标。
6. **部分完成**：请求两处矿，只留一处可达。完成一处后应报告实际完成 1/2 和阻塞原因；恢复信息应包含相同原因及最新资源状态。

对第 1 项，“发现地下有矿”不等于“能直接挖到矿”。本版不会为了到矿脉而自行扩大为挖通道任务。
