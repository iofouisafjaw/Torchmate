# TerrarAI 0.10.30 实机验收清单

状态：全部待玩家执行。自动化通过记录见 `tests/verification-source-replacement.json`，不代替本清单。
本清单只安排本机验收，不授权发布，也不自动修改 `release/acceptance.json`。

## 测试准备

- 使用可丢弃的测试世界和经典角色；备份准备升级的旧配置、角色与世界。
- 第一轮只启用 TerrarAI 和必要依赖；可选模组留到 P2 加回。
- 在模组管理确认 **0.10.30**，不要只凭文件名判断；核对新青绿色像素机器人图标。
- 背包保留正常镐、斧头；准备木材、石块、木平台、工作台、普通箱子、少量治疗药水。
- 准备平地树木、暴露的可挖矿石、平台/台阶、门、浅坑和一段可观察的水池。
- 生存测试先关闭作弊。测试移动、血量和物品计数时可暂关自动反击/自动治疗，测对应功能时再打开。
- 为区分暂停来源，先关闭原版自动暂停；普通聊天不暂停，工坊选址/预览按对应流程暂停。恢复世界后才观察施工。
- 记录 Windows、Terraria、tModLoader、实际 GGUF 文件、后端、启用模组、游戏分辨率/UI 缩放。
  编译基线为 Terraria 1.4.4.9 / tModLoader 2026.8.3.0；其他组合单独记录。
- 历史服务别名 `qwen3-4b` 可以继续存在；实际权重以启动日志/服务身份为准，不能凭别名判断加载了4B。

建议顺序：P0 全过后做 P1，再按自己会使用的功能做 P2。P0 中出现未确认消耗、停止后继续改世界、物品丢失或保存异常，先记录并暂停后续资源任务。
每项填写 **通过 / 失败 / 未测 / 不适用**；未测和不适用不计入通过。

| P0-03 | 中文输入和暂停 | 逗号打开聊天，直接用中文输入法输入一整句；候选确认、退格、粘贴、Enter发送、Esc关闭；观察世界时间或远处敌怪。再打开平台选址/预览。 | 候选确认不误发、一次只发一条、输入不移动角色；关闭后键鼠恢复；关闭原版自动暂停时普通聊天仍推进世界，工坊预览按流程暂停。 |
| P0-04 | 模型离线也能控制 | 记下原模型地址，临时改为 `http://127.0.0.1:1/v1/chat/completions`；依次说“等待”“继续跟随”“召回”“停止”，再恢复原地址。 | 控制无需等模型超时；等待会留在原地；跟随恢复；召回在有安全位置时到附近；停止结束任务/攻击并恢复跟随。“停止”不等于“等待”。 |
| P0-05 | 停止和迟到响应 | 模型连通时发采集任务，在模型仍规划时立即“等待”；等到旧请求完成或配置的超时过去。再在实际采集中“停止”。 | 迟到响应不启动旧动作；执行停止后不再新增该任务的移除/扣料；已完成部分保留；模型或任务条不能把取消报成已完成。允许停止瞬间之前已发生的变化。 |
| P0-06 | 确认、拒绝和旧确认 | 先说“以后采集先问我”，用“记忆”核对已保存。发“帮我砍1棵树”，记录背包和目标；先拒绝。重新下令，再明确同意。另试在等待确认时改规则或切换昼夜；过期测试等待超过两分钟。 | 需要确认的动作在确认前不执行；拒绝后不执行；有效同意只执行当前动作；旧任务、改规则、跨昼夜或过期的确认不能复用。若偏好未保存，先记为偏好解析失败，不能算后续许可测试通过。 |
| P0-07 | 满背包、部分拾取守恒 | 玩家在同伴附近先丢20个石块，再填满50格主背包且不留石块容量，保留工具；退开避免自己吸取，让同伴完成一次砍树触发拾取。第二轮仅给现有石块堆留5个容量，再触发拾取。最后腾出足够空间重试。 | 第一轮地面20个石块保留；第二轮只入包5个、地面剩15个；腾空间后余量可拾取且不复制。测试中防止玩家、其他模组或其他物品合并干扰；只核对这堆已知数量的石块。 |
| P0-08 | 保存、退出与世界隔离 | 保存一条“采集先问”的偏好并做少量施工；在另一任务等待确认时退出。重进同世界，再进入另一个世界。 | 已建内容和原世界偏好保存；旧任务、确认、护卫和协作不会自动续跑；另一世界没有继承该偏好。重进后默认跟随，只有一位同伴。 |

## P1：验证重写后的执行层与主要任务链

| 编号 | 要测什么 | 怎么测 | 什么结果算通过 |
|---|---|---|---|
| P1-01 | 行走、动画和复杂地形 | 作弊关闭，分别让同伴跟随通过平地、1格台阶、平台、浅坑、可绕开的墙；每次只增加一种障碍。再安排确实不可达的目标。 | 外观和朝向正常；可走路线能完成；不穿墙、不自行挖开路线、不借作弊传送。不可达时停下/报告受阻，不能无限抖动或宣称已到达。 |
| P1-02 | 开门与水下移动 | 在连续地面放可通行的关闭门，玩家穿过去；再穿过浅水、较深水池并上岸。分别在门口和水中“等待/停止”。 | 门正常打开，同伴通过且不拆门；水中能跟随并尝试上岸；停止/等待不被旧路线覆盖。复杂水岸无法通过时允许明确失败，不能穿地或假报到达。 |
| P1-03 | 定量砍树和挖矿 | 新目标先测“砍1棵树”，再“砍3棵树”；选实际存在且工具足够的暴露矿石，说“挖1处铜矿”（可换世界中的矿种）。记录目标、周边方块和入包量。 | 可达目标按数量结束，不继续挑新目标；普通挖矿的3×3范围是预期行为。“1处”不等于1个矿石掉落。直接移除数与实际入包量分别报告，没有效果不能算完成。 |
| P1-04 | 工具/目标中途失效 | 采集中从主背包移走斧头或镐；对另一处目标，在同伴工作前用别的方块替换它；换成镐力不足的矿再试。 | 停止或重新核实，不使用失效工具、不破坏替换后的未知目标、不免费生成工具；任务明确未完成，保留已完成记录。 |
| P1-05 | 有界竖井和探路 | 平坦无建筑处说“往下挖4格”，观察预览后确认；另一次在前方布置水/沙/家具等受保护障碍。再朝一个方向说“去前面探探”，途中转身。 | 三格宽固定竖井逐层执行，自然下落、终点地板保留；危险/保护检查在破坏前停止。探路沿发令方向、不自行挖路；发现资源/危险有真实报告，无法返回要明确说明。 |
| P1-06 | 附近箱子存取 | 在18格内放一个普通完整空箱；背包备20木材，说“把10个木材存进附近箱子”，再“从附近箱子取5个木材”。测试存不下/取不够，以及含收藏物品的情况。 | 首次背包-10、箱子+10；再背包+5、箱子-5。总量守恒，数量不足不能报足额完成；不突破收藏、锁箱/占用等既有限制。查询本身不转移物品。 |
| P1-07 | 完整合成链 | 背包只放一部分材料，另一部分放附近可用箱子；发“做一套铁盔甲”。核对材料与制作站预览，确认前等待，再确认；第二次移走所需材料或制作站。 | 确认前不取料、采集或合成；优先使用已有资源，缺口才进入允许的采集；成品、消耗和制作站与实际相符；失效时停下说明，不能把计划当成果。 |
| P1-08 | 平台和最终核验 | 先测“三层、每层20格平台”，按界面选址，核对60个目标格与已有平台复用量，再确认。第二次在最终核验前拆掉一格早先已放平台。 | 预览、层数、长度、材料一致；只扣新放材料；不覆盖障碍。第一轮连续完整且核验通过；第二轮必须报未达标，不能仅凭施工循环结束就报成功。 |
| P1-09 | 失败恢复闭环 | 另用较长平台或合成任务，确认并部分执行后移走剩余材料；附近箱子也留出明确缺口。记录失败，再向箱子补少量材料，让同伴“先查材料”或重规划；新预览先不确认，最后确认。 | 返回实际原因、已完成部分、最新资源；补查能读到变化；新计划保留原目标/范围、复用已达标部分，旧确认无效。新确认前不消耗或施工；无法继续时询问或停止，不循环补查或假报完成。 |
| P1-10 | 房屋检测和修补 | 准备一间原本合格的NPC小屋，只拆掉唯一光源；站附近说“检查这个房子能不能住”，按UI选择/核对目标，再确认修补。 | 能指出实际缺项；确认前不放置、不扣料；修补后重新做原生入住检测。无法定位或修补的原因应明确，不能只说“修好了”。 |
| P1-11 | 战斗与保护 | 向导旁放普通敌怪，说“保护我”，再试“清理附近小怪”；关闭自动反击检查跟随，再手动保护；攻击中“停止攻击/等待”。 | 仅敌怪受击，城镇NPC/宠物不受伤；不隔墙扣血、不把逃跑当击杀；开关能关自动反击，手动保护仍可用；停止后不再产生旧攻击，原地等待不追怪。 |

## P2：常用功能与组合场景回归

| 编号 | 要测什么 | 怎么测 | 什么结果算通过 |
|---|---|---|---|
| P2-01 | 定位与地图 | 在已探索区域准备实际存在的矿、完整箱子和床，分别问“最近的铁矿在哪/附近箱子在哪/我的床在哪”；查看小地图和全屏地图，随后拆掉目标。 | 方向、距离、坐标和图标对应现场；查询不采集、不取物、不改出生点；目标失效后标记失效。矿种要换成世界中实际存在的种类；120格外或未探索目标应按范围说明。 |
| P2-02 | 克眼准备协作 | 分行发送“一起准备打克眼”“药水我来”“竞技场你来”“继续协作”；先不满足玩家药水项就“核验协作”，再按实际目标补齐并核验。途中交接或暂停一次。 | 展示分工和预览；玩家负责项不被同伴代做；“我做完了”不能冒充库存证据；继续/交接不能代替施工确认，进度与现场一致。 |
| P2-03 | NPC住房协作 | 发送“协作扩建2间NPC住房”“备料你来”“住房我来”“继续协作”；先核验空地，再按蓝图施工后核验；也可在未完成时交回“住房你来”。 | 玩家施工时同伴确认施工被禁用；空地不能验收通过；交接保留原位置，后续仍需新确认；最终同时通过蓝图和每间房的入住检测。 |
| P2-04 | 种植与草药 | 合适草地/空花盆处准备种子，说“种3颗橡实”“种5株太阳花”；在开花和未开花草药混合处说“采收草药”。 | 确认前不种、不耗种子；种植数/扣种子一致；保留未成熟草药，采收以实际入包为准。种橡实完成看幼苗，不要求立即长成树。 |
| P2-05 | 自动治疗和提醒 | 暂用可控的小怪降低生命，背包放普通可用治疗药水；观察治疗后原生冷却。分别关闭自动治疗、提醒总开关再复测；等一次正常入夜。 | 治疗扣一瓶并产生对应回血/原生冷却，冷却中不连喝；关闭后不自动治疗。提醒不高频刷屏，开关有效；治疗与低血量提醒不重复轰炸。测试时避免其他回血效果干扰。 |
| P2-06 | Wiki和实时问答 | 问“我的生命值是多少”，再问一个需要Wiki的攻略问题。有索引和无索引分别记录，不必为此下载新语料。 | 实时状态吻合；问答不启动采集。检索回答能给对应来源，无资料能说明不足；不得把模型猜测包装成已检索事实。没有Wiki安装时该分支记“未测/无索引”。 |
| P2-07 | 作弊统一门禁 | 关闭作弊，说“时间改成21:00”“天气改成下雨”“召唤克眼”“把世界出生点设在这里”；在另一个可丢弃世界打开作弊测试时间/天气。Boss另选符合条件时测试，最后退出重进。 | 作弊关闭时四类世界操作都拒绝且现场不变；打开后仅合法请求生效，条件不符给原因；退出后不继承作弊授权，不修改首领击败进度来伪造完成。此项必须与正常生存结果分开记录。 |
| P2-08 | UI与常用模组 | 1280×720、1920×1080及常用UI缩放下检查聊天、长任务卡、确认按钮、框选、Esc取消与地图；随后逐个加回常用模组重测箱子/合成/放置。 | 不遮挡关键按钮、不越界、点击UI不同时挥工具；框选不误吃打开工坊的点击。启用的可选模组组合分别记录兼容性，未测组合不作通过声明。 |
| P2-09 | 长时间游玩 | 保持实际14B/所选模型运行，交替聊天、跟随、采集、合成和开关地图20–30分钟；记录空闲与推理时FPS、显存、响应时间。 | 无崩溃、持续卡死、同伴重复生成、旧动作复活或明显持续资源增长；性能达到你预先设定的可玩标准。长推理与模型不可用需区分，不把延迟自动判成逻辑失败。 |
