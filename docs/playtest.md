# 游玩验收：同伴是否听进了纠正

先按 README 启动模型并安装 `dist/TerrarAI.tmod`。使用测试世界；挖矿会改变 3×3 范围。为便于复现，把模组配置中的 Temperature 设为 0，保持相同模型和推理设置。

## 0.10.27 恢复解码与定位回流

本轮运行真实本地模型离线评测，未进入游戏世界；以下由玩家实测。

1. 让平台／合成链任务部分失败，检查模型能生成新的原范围预览；新预览确认前没有备料施工，旧确认仍无效。
2. 恢复阶段要求补查箱子／矿／床的定位，确认返回查询结果后仍能询问或重新规划原任务；连续重复同一定位应结束查询，不循环刷标记。普通“最近的铁矿在哪”仍可直接显示结果结束。
3. 挖掘遇熔岩、战斗无法安全接近或执行异常后，检查模型只补查、询问或停止；不能通过普通长任务工具、作弊或空字段重规划绕过限制。
4. 合成恢复中连续查同一个配方，应进入重规划／询问／停止选择，不能只根据“现在能做”宣称已经做成。停止回复应由程序显示未验收状态；询问后回复新信息可重新补查，不能扩大原权限。
5. 模型请求期间停止、拒绝、换任务或死亡；确认旧响应无效，且没有新的材料消耗或施工。

## 0.10.26 长任务失败恢复

本轮仅自动化通过；以下实机验收均待玩家执行，没有启动客户端、模型或世界，也未部署到个人Mods目录。

1. 创建合成链／三层100格平台，确认后让后续制作站、材料或通道失效。检查任务保持失败，聊天显示真实原因、已完成部分、最新背包和可用附近箱子。失败后把物品移入／移出箱子，检查下一次补查读到新数值。
2. 让Agent补查后重新规划：平台／建筑保留原位置，已达标部分复用；合成重新算原目标的剩余缺口。新预览出现后不点确认，观察没有拿料、合成或放置；旧确认不能继续。再确认后才施工并重新验收。
3. NPC房屋修补／克眼准备做到一半后使现场失效，检查收据和原位置预览；植物种植／采收失败后，在其他位置增加候选植株或改变库存，检查刷新确认仍只针对原未完成位置，不补采替代植株。
4. 采集部分后附近无可达目标，检查未标目标完成，已移除数量不冒充背包入包。挖掘遇危险、战斗无法接近或执行异常时，应查询、询问或停止，不自动扩大采集范围或重启战斗。
5. Agent询问后答“先查材料”：应继续原恢复上下文；答“同意”也不能代替新预览确认。说“算了”“不用了”“停止恢复”、点停止／拒绝、换任务、死亡、退出世界或更换同伴后，旧模型响应不能继续。
6. 作弊关闭、关闭后重开及原采集“先问”偏好下重试：恢复不获得新作弊权限，不自动购买、取箱子、采集、放置或调用别的长任务。每条链最多2次恢复、6次模型请求、2次重规划；超过限制或等待5分钟应停止并保留成果。
7. 模型断连或输出损坏时，应保留原失败收据并停止；建筑跳过受阻格子不能显示整张蓝图验收通过。


## 0.10.18 近战护卫与清怪

此节是待玩家执行的手测清单，当前自动化结果不能代替它。使用测试世界安装0.10.18；直接的保护／清理／停手指令不需要模型，先关闭模型验证这些入口。

- 在向导、城镇宠物或城镇史莱姆旁安排一个普通小怪，分别说“保护我”和“清理附近小怪”；观察只对敌怪扣血，城镇NPC、宠物和附近小动物不受伤。再检查训练假人、无敌敌怪、友方化敌怪及代表性模组城镇NPC。
- 空闲跟随时让小怪进入8格附近，检查自动接敌、近身挥击、击退、伤害文字和打完后的跟随恢复。关闭设置里的“跟随时自动反击”，确认自动出手停止，但“保护我”仍可手动启动。等待、采集、建造、合成预览和执行时不能抢移动去追怪。
- 保护时跑远，同伴应先回到玩家附近，不继续远距离追怪；清怪则保持发令时24格范围。用门、平台、坑边和水中路线检查接敌；隔墙必须绕路，不能站在墙后直接扣敌怪血。飞行高处和不可达目标应停下／回到玩家身边并给出未完成说明。
- 对照不同原版进度下的基础伤害上限（8、10、14、18、26、34、42、50、60）及出手间隔（至少48帧）。把高伤害快武器放进背包，确认仍有限制；取走适用近战武器后应使用同伴木剑，不增删玩家物品，不消耗弹药或魔力，不发射玩家武器弹幕。
- 在挥击前后说“停止攻击”“停止”“等待”，以及新采集／建筑指令；后续不能继续扣血。停止后说“继续跟随”应恢复自动反击；等待期间仍保持等待。死亡、暂别、换世界后不恢复旧护卫／清理任务，也不打NPC数组槽位中后来生成的另一目标。
- 清怪后检查至少约1.5秒的重新扫描，再出现小怪应重置核查。怪逃出范围不能算同伴击杀；不可攻击／不可达的小怪仍在范围内时必须报未完成。持续生成或高血量目标最多清理60秒游戏时间，不能因超时而报成功。
- 暂停游戏后不能出手、移动或推进清场核查；继续后恢复。聊天窗口不暂停游戏。问“清完了吗”“你打了几个怪”“保护得怎么样了”应读取实际记录，不能取消任务或捏造击杀。
- 对照 `learning.jsonl` 的 `combat_started`、`combat_hit`、`combat_finished`、`combat_cancelled` 与实际敌怪生命和击杀；自动反击事件不附到已经结束的旧工作上。检查正常掉落与玩家击杀参与记录，以及代表性模组的命中／免疫／复活钩子。
- 检查Boss及共享生命部件不会被选中。特殊Boss部件、模组敌我标记、飞行目标、武器贴图缩放和挥击方向均仍需实机兼容性检查。

## 0.8.1 平台施工检查

- 备份测试世界，准备至少 60 个成品木平台；模型地址可暂改成不可连接端口。进同伴页点框选，拖出宽 20、高至少 13 格的空中范围，松开。确认前背包数量与世界都不变，敌人和生命值暂停；打开工坊的那次点击不能被当成选区起点。
- 默认三层、间距六格；查看蓝图每层位置与材料预算。切换层数或间距时蓝图和预算更新。选得太矮、太宽或碰到世界边界时不能确认；只在地形显示区域拖动，避免在 UI 控件上结束拖动。
- 框到树、房子、家具、背景墙、电线和液体：冲突标红且不能开工。重新选一个树在层间、不挡平台行的位置，施工后树与墙保持不变。已有正常平台计入复用，不能重复扣料。
- 点确认后每隔几个游戏刻出现一格平台；主背包扣量等于新放格数。打开同伴面板或原版暂停后，世界和扣料均停止；继续游戏后恢复。原版正常右键交互不应自行取消正在运行的施工。
- 施工中按 HUD 等待／停止，或点工坊取消：后续不再铺，已铺保留。拖走背包剩余平台，或在待建位置放一个箱子等障碍，应明确停止，不能覆盖或免费继续。材料不足一开始就不能确认。
- 完成核对各层是否连续、长度／间距是否与蓝图一致，且任务卡标“施工达标”。在快完工时挖掉早先放好的一个平台，最终必须报未达标；“结束施工”不能冒充通过核验。
- 测试右键／Esc 取消框选及预览、反向拖动、窗口与 UI 缩放、点击按钮不同时挥工具、详情页与 HUD 的暂停／取消状态。关闭或隐藏的工坊不能拦住游戏点击。退出再进不恢复旧任务，原有已施工方块正常随世界保留。
- 查看 `learning.jsonl` 中 `construction_confirmed`、`construction_placement`、`construction_cancelled`、`construction_audit`；与实际材料和方块核对。工坊操作不应新增模型请求。实际绘制、鼠标事件与不同模组共存仍需要本节手动验收。

## 0.8 基础控制与任务卡检查

- 暂时把模型地址改为 `http://127.0.0.1:1/v1/chat/completions`，记下原地址以便恢复。用小 HUD 的等待／跟随／停止／召回，均应立即生效，learning.jsonl 不应因此新增模型请求；模型失联不应锁住基础按钮。结束后恢复原地址。
- 点击等待，走远到原先会自动召回的距离。同伴应留在自己的等待位置，不追玩家；有重力时可以落地。继续跟随后应恢复跟随，召回应立即回到附近。分别测试平台、台阶、浅坑和门，记录卡住情况；这一版没有新增完整寻路。
- 等待时普通聊天、问答不应让同伴跟上来；明确给一个新采集任务则结束等待。退出世界再进，恢复默认跟随，不恢复旧任务或旧许可。
- 模型正在理解或规划时点击等待，等旧请求原本足以返回的时间：同伴仍等待，任务卡保持取消，旧回复不能启动动作。执行中点等待／停止，不能继续下一步；已经移除的方块不会复原。
- 采集等待同意时，任务卡应显示实际动作和目标坐标；同意后显示准备状态，关闭大面板才执行。再用等待打断，旧同意不得继续使用。卡片中核实的目标移除数与 learning.jsonl 收据核对；模型结束任务仍应标记整项目标未核验。
- 任务失败或被取消后，保留原因与最近实际结果；再发新任务，迟到的旧规划或错误不得覆盖新卡。点击 HUD 的任务按钮和聊天页任务卡，均能看到同伴页完整详情。
- 在 1280×720、1920×1080 和 UI 缩放 100%／150% 检查 HUD、六个基础／确认按钮、任务卡与输入框。小窗口可用简版卡并点开详情；文字不越界。HUD 本身不暂停，展开大面板才暂停；点 HUD 控件不应同时挥镐或攻击。

## 面板与问答回归检查

- 点击左侧 HUD 的头像或标题展开同伴小屋；默认不绑定快捷键，按 P 不应再开关面板或干扰原操作。拖动标题，改变窗口大小与 UI 缩放，检查五个分页和底部控件仍可操作，长内容能滚动。
- 打开面板后，单人世界暂停；观察敌人、昼夜和生命值均不再推进，模型仍能返回回复。点击继续游戏后恢复。暂停不是给角色加无敌或让模型负责防卫。
- **不要先按 Enter**，点击聊天输入框直接输入英文。试中文候选词、退格和粘贴；输入不应移动角色。候选词的 Enter 只确认文字，再按一次 Enter 才发送；长按不重复发。原话只出现一次，原生聊天条不打开。点击发送也有效，回复和确认提示进入同一消息列表。
- 关闭面板后按 Enter，原生聊天应恢复；面板关闭时仍按住 Enter 不应立即打开原生聊天，松开再按才生效。
- 模型正在理解时，发送和检查连接不可重复点击；停止可取消对话和任务。规划或执行时仍可发送纠正，沿用中止旧任务再理解的规则。
- 没有待确认动作时同意／拒绝不可点；具体采集动作等待时才启用。同意后仍应暂停，关闭面板才执行该动作；暂停不应造成移动停滞或重试计时误报。昼夜切换或规则更改后，旧许可仍应失效。
- 关闭面板后角色应恢复键盘和鼠标操作。重进同一世界，记忆仍在；换世界，面板草稿与消息列表清空，记忆不串档。
- 打开世界近况，对照存档名称／难度、背包木材数量、生命值和已击败首领；消耗物品或改变生命后重新打开／刷新，数据应变化。查看此页无需连接模型。
- 问问同伴中问“我的生命值是多少，附近有几个敌怪”，与世界页对照；再问“箱子里有多少铂金币”，应说明未读取箱子。检查 learning.jsonl 中有 inquiry_request／response，偏好列表没有增加。问答不能启动采集动作。
- 问答等待时点击停止，应取消；未完成就退出换世界，旧回复不能显示。问答不取消已有任务，但关闭面板后已有任务会继续。
- 同伴页暂别后再唤来，不应重复创建多位同伴；偏好仍在。记忆页忘记一条后，重进世界核对删除已保存。

以下 `/ai` 实验也可在面板中去掉前缀直接发送，`memory` 用记忆按钮，`同意` 用同意按钮；查看行动结果前必须关闭面板恢复世界。

## 澄清循环与不支持的请求

发送“保护我防止被攻击，而且以后采集的时提前跟我说一下”：应说明当前支持近身小怪护卫、不能保证免伤，启动任务请单独说“保护我”；同时提取采集偏好，保存为不限时段的采集前确认。当前世界恰好是白天，不能成为限定规则的理由。

若确实遇到一个时段澄清问题，回答“适用于白天，晚上你可以自主采集，但是保护我的命令任何情况”：应提取白天先问、夜里不用两条采集规则，并解释近身护卫的范围，不能把保护存为communication偏好，也不能重复同一个时段问题。回答已知时段问题的“白天／夜里／都适用”走绑定候选规则的结构化解析，不再额外调用模型；脱离该等待情境的“都适用”不能自行创造规则。无法完成的澄清应明确报告没有保存，而非无限重复。

完整原话仍用于来源证据。传给偏好模型的文本会分离即时护卫请求，输出语法只允许玩家原话提到的时段；这些是工程约束，不是模型权重学习或泛化成绩。

## 一次完整实验

1. 用 `/ai status` 记下本世界的数据目录。没有旧规则的世界可先作为对照，观察同伴是否直接执行采集。已有规则用 `/ai memory` 检查，避免误把旧规则当新学习。
2. 教它：`/ai 以后夜里采集先问我，白天不用。`。保存回复和 `/ai memory` 应分别显示两个时段；不要只凭它说“好的”判断成功。
3. 夜里在有镐、有可达铜矿的地方，用新坐标下令：`/ai 挖 tile(X,Y) 的铜矿，挖完这个目标后结束。`。等待期间目标应不变；`/ai 同意` 后才采集。
4. 白天换一个目标，再发采集任务。应直接执行。还可换成砍树，检查动作类型和目标，而不只检查有没有询问。
5. 纠正：`/ai 我改主意了，以后白天采集也先问我。`。白天的新目标应开始等待确认。
6. 在任务等待时说 `/ai 刚才那次，以后别这样了。`。同伴应问清楚，规则与目标暂时不变。回答 `/ai 夜里采集要先问，白天直接采集。`，应修改白天规则并重新规划原任务。
7. 退出再进同一世界，在新目标重复昼夜测试；进入另一个世界，检查偏好没有串过去。

确认只对当前目标有效。昼夜切换、规则修改、两分钟超时后，旧确认应失效。`/ai feedback <纠正>` 只更新记忆；要执行任务需重新下令。

## 0.10.19 地点查询与地图标记

本节为玩家待执行的手测清单，本轮没有运行游戏世界或图形客户端。

1. 在已探索区域留两处不同距离的同种矿，另留一处更近的未探索矿。断开模型连接，发送“最近的铁矿在哪”：应选择120格内最近的已探索铁矿，报告方向、直线格数和坐标。再试“最近的矿在哪”、钛金矿、陨石、黑曜石；镐力不足仍可定位。超过120格、圆形搜索边界之外或完全未探索的目标不应泄露坐标。
2. 在小地图、叠加地图、全屏地图分别检查图标位置；缩放、平移、改变分辨率与UI比例，远离视口的图标应被原生地图裁剪。鼠标悬停显示目标名、坐标及当前方向距离；走到图标另一侧应改变方向。地图关闭时按提示启用地图。
3. 准备距离不同、已探索的普通箱、命名箱、上锁箱、打开的箱。发送“附近箱子在哪”：选最近的完整箱子，只标位置；背包及箱子内容不应变化。“查附近箱子”仍只读18格内可用箱的内容；原有存取、合成回归不应受影响。
4. 试两种朝向、不同材质的完整床，从各占地格附近查询“床在哪”。分别设置近处／120格外的床为个人出生点，再问“我的床在哪”：应优先标个人床，说明只核实床仍在。没有个人床、原床被拆或出生点未对应完整床时，应说明没有找到，再找附近普通床，不能把它说成个人床。核对查询前后角色出生点不变。
5. 连续查询矿、箱子、床，应各保留一个；同类新查询只替换该类。发送“查看标记”核对，走到无矿处再查同种矿应清掉旧矿标记并说明范围。挖掉已标矿、拆箱／拆床、更换个人出生点，对应标记应失效；不擅自改标相邻目标。“清除标记”清空三类，退出重进／换世界／换角色不能继承旧标记。
6. 在采集、保护、施工或合成链执行期间用上述明确问法查位置，关闭面板后原任务应继续；查询不自动采矿、开箱、传送或移动。另用更自由的说法验证模型确实调用 `locate`，返回由真实查找提供的位置，不自行编造。

## 0.10.20 向下挖掘与短程探路

本节留给玩家执行。本轮只做自动化，没有进入世界、启动图形客户端或运行真实模型。

1. **竖井与深度**：先备份测试世界。在无建筑、液体、电路和落沙的普通石土地段，让同伴在12格内站稳，背包放镐，断开模型连接。说“往下挖4格”：应三格宽、逐层先两侧后中间，挖完自然下落，终点地板保留。对照实际移除数、脚下深度和任务卡；地面掉落保留，不能凭移除数说材料进了背包。作弊开关打开也不应传送、生成工具或跳过范围检查。
2. **地下层**：地表附近说“挖到地下层”，核对本世界地表线和同伴身体实际进入地下；已在地下时应直接提示。距离地下层超过160格时提示靠近，不无限向地狱挖掘。试“往下挖16格”“往下挖0格”“往下挖161格”，错误长度不能被静默裁剪。
3. **中断与保护**：在剩余竖井周围放家具、可住房背景墙、电路、制动器或染色方块，再试液体、沙／泥沙／雪泥、尖刺、滚石、工具不足、无安全支撑。应在破坏受保护处之前停止并解释，已挖部分保留。执行中移走镐、替换目标方块、旁边放家具或移走落脚点，不能继续使用过期检查。
4. **偏好与确认**：禁止挖掘时直接拒绝；设“以后采集先问我”，任务卡应显示完整三格列、起止深度，确认前不挖。同意仅授权本次固定范围；换任务后旧按钮无效，等待两分钟、修改规则或昼夜改变均失效。探路不挖矿，不应要求挖掘许可。
5. **探路往返**：玩家分别面向左／右说“去前面探探”，途中改变玩家朝向，同伴仍按发令方向寻找32格前方落点，完成后尝试回到原出发点。核对平地、高差、平台、可开门和绕路；返程途中堵路，应该报告回程失败而不是传送或声称已经回来。不能挖墙或拿箱子内容。水面、尖刺、可见敌怪和大于12格深坑前应停下；不能凭报告推断无陷阱或不受伤。
6. **真实发现与地图**：在可见矿／箱子／已识别危险旁放一个墙后同类物件，核对12格视距和视线限制。报告只含实际可见发现；相邻同类矿不刷屏，最多12处，危险优先。矿／箱子／床／危险每类最多一个图标；同伴在玩家未探索区域的实地观察可以留下标记，但不应点亮周围地图。拆物件、填平深坑、敌怪离开或换世界后对应标记应失效；“清除标记”仍可用。
7. **控制与记录**：执行中问“探完了吗”“发现什么了”“挖到地下层了吗”，应读记录且继续任务；“最近的矿在哪”仍是玩家附近地图查询。“停止／等待／回来”、新任务、角色死亡、暂别、世界退出应中止。任务正常或失败结束后原地等待。用系统暂停检查动作、观察和任务执行预算不推进；学习记录应有 `expedition_started`、实际移除及结束／取消收据，观察记录不能算成已获得物品。

## 0.10.21 主动提醒

本节为玩家待执行的手测；本轮只跑自动化，没有进入世界、打开图形客户端或调用真实模型。

1. **设置与显示**：在模组配置中核对“主动提醒”总开关和四个分项，中文／英文标签可读，默认开启。断开模型连接，同伴在场，观察开关是否生效。关闭聊天窗口后提醒应显示原生文字，打开聊天时应进同一记录；不能自动打开窗口、抢键鼠焦点或取消当前采集／施工／探路／护卫。
2. **天黑与血月**：从白天等到夜晚，普通夜晚只一条；直接进入已是普通夜晚的世界不补发。血月开始或进入正在发生血月的世界，五秒安静期后可提示；天黑与血月同时发生时不连发两条。单独关闭血月项仍应允许正常天黑提醒。加速昼夜或反复改变血月状态，不应绕过冷却。
3. **生命阈值**：核对有效生命上限的30%与31%边界，提示中的当前／最大生命与游戏一致。小幅治疗到44%再掉回30%不应重复；治疗到45%后再降低，仍需满足同类五分钟间隔。持续低血量不定时刷屏，死亡时不提示。等待共享冷却期间若已治疗到31%以上，不补发过时低血量；只提醒，不自动喝药。
4. **背包空位**：将50格主背包分别留4、3、0个空位，核对提示与数量；钱币、弹药格和魔法存储等不计入主背包。物品仍可叠加并不等于拥有空格。整理到7格再装满不应重复；整理到8格可重新计次，但仍受五分钟间隔。只提醒，不自动存箱子或移动物品。
5. **频率与过时事件**：同时低血量、血月、快满包，先提示生命，之后任何两条至少间隔60秒，不逐帧刷屏；状态恢复或事件结束后不补发旧提示。普通天黑消息若受同类冷却压住超过两分钟应丢弃。施工进行中、聊天关闭时也应看得到提醒。
6. **生命周期**：总关闭后保持静音，分项关闭只影响该类；切换开关／暂别唤回不应重置本轮已提示状态。重启用或同伴返回先安静五秒。关闭期间错过的天黑不补发，当前仍有血月／低生命／满包时可按规则提示。系统暂停不消耗安静期或冷却；死亡、换角色、退出／换世界不应交付旧提示或串提醒状态。
7. **记录与回归**：实际提示才应产生 `companion_reminder` 收据；没有模型请求、任务修订或背包／生命修改。触发提醒时已有任务继续；地图查询、施工确认、存取箱子与普通对话保持原行为。

## 0.10.22 克眼战前准备

本节留给玩家执行；本轮仅自动化与隔离打包，没有进入世界、启动图形客户端、安装个人模组或调用真实模型。

1. **入口与预览**：断开模型，说“帮我准备打克眼”。应自动显示3×100平台、层距6格、2篝火／2心灯及支撑。左键场景重选，绿色已有、蓝色待建、红色障碍；详情列出药水（铁皮／再生／敏捷各2、弱效治疗10）、来源、缺料、制作站和坐标。确认前核对背包、箱子、地形均未改变。试UI比例、鼠标焦点、刷新按钮、取消和旧按钮。
2. **材料与站点**：从空原料准备、背包已有成品、附近箱子有中间件分别测试。核对真实配方产出和共享材料没有重复扣费；心灯链条批量余料保留。缺生命水晶、草药、凝胶或水时只列缺项，禁止开工。背包带玻璃瓶但没有工作台时，计划应先补工作台再放瓶；工作台／熔炉／砧缺安全空位应提示。站点不得占竞技场及其净空，不能预览时临时放站再移除。
3. **确认失效**：看完预览后移动、改变背包或箱子、开箱／锁箱、改现场、关闭篝火或心灯、拆站、等两分钟，再按旧确认。应先刷新并要求再次确认，不能直接扣料。补齐缺项后点刷新，检查新的材料和取箱范围。
4. **执行**：确认后先完成合成链，再从下往上铺平台、放木支撑、篝火、心灯。玻璃瓶放在实有工作台上。已有合格平台／设施复用；遇树、墙、玩家建筑、液体或线路不拆不盖。试采集前询问偏好、无斧／镐、材料不在28格范围、箱子离开18格范围或主背包没有空位；失败要如实说明且保留完成部分。
5. **验收**：核对平台连续、没有坡／半砖／虚化，每层净空，木支撑、篝火、心灯完整开启，药水在主背包。分别在末尾拆一格旧平台、拆木支撑、破坏家具局部、关闭设施、用掉一瓶目标药水，不能显示全部完成。独立核对游戏实际Buff在竞技场内的覆盖、跳跃和走位；自动化通过不替代这些手测。
6. **控制与回归**：备料、铺设、放家具三阶段分别停止／等待／召回、新派任务、死亡、退出世界，后续不得继续执行；旧按钮不能确认新任务。系统暂停不推进动作。完成收据 `arena_audit` 只有实际重检通过才 `passed=true`。重跑普通平台、小屋、合成铁套、箱子存取和主动提醒；查询地图不应取消准备任务。

## 0.10.23 种植与草药采收

本节留给玩家执行；本轮仅自动化与隔离打包，没有进入世界、启动图形客户端、运行真实模型或安装个人模组。

1. **种橡实**：让同伴靠近12格内，主背包放橡实，在开阔普通／神圣草地说“种3颗橡实”。看计划、种子来源、坐标，确认前地形／物品不变。确认后同伴应走近、逐颗扣种子，按原生树苗规格完整放置并保留间距。树苗自然长成树也应通过最终检查。泥土、斜坡、液体、线路、背景墙、已有草／树／家具或净空不足不能被清掉强种；不能凭空补橡实。试停止、种子被拿走和空位变更。
2. **七种草药**：分别在空花盆、种植箱及对应自然土壤种太阳花、月光草、闪耀根、死亡草、幌菊、火焰花、寒颤棘。“种草药”从已有草药种子选择，不种橡实、不在同一格重复扣种子。背包部分种子、附近箱子部分种子时先用背包再取差额；打开、锁住、过远或替换的箱子不取。草药花盆所在背景墙保留。缺种子／空位不开始，不能催熟或自动造土、花盆。
3. **采收状态与掉落**：准备同种幼苗、成熟未开花和开花三种状态，说“采收草药”及“采收5株太阳花”。只选安全开花植株；自然昼夜、雨、月相或植株更新改变条件时不继续使用旧计划。核对原生真实草药与种子进入主背包的数量，未拾取／放不下的残余必须留在世界。背包只剩一个空位、叠加将满、模组改变掉落或当前手持再生法杖等物品时特别检查；不能把移除成功当作已收到草药。
4. **药水原料衔接**：给齐其余材料和制作站，分别在背包已有草药、箱子有草药、只有附近开花草药三种情况下规划再生／铁皮／敏捷药水；应依次复用已有库存、再采实际缺口，草药采集不需镐。一个植株产出超过缺口时不额外采，余料与种子保留。不足或无开花植株只提示缺项，不能把种子算作成品草药，也不等待数小时或强制生长。克眼准备同样测试草药供料。
5. **偏好与确认**：设“以后采集前先问我”，确认整份任务后，每株采收仍按偏好询问。只禁止挖矿不会禁止采草药；白天／夜里规则按当前时段，规则、昼夜、目标变化或两分钟过期后旧同意失效。主计划的库存／位置／箱子／植株变化也应先刷新再确认。旧按钮不能确认新任务。
6. **寻路与生命周期**：试平台、门、高差和不可达植株，使用现有寻路，不能挖墙、瞬移或远距离操作。系统暂停不推进动作；停止、等待、召回、新任务、死亡、暂别或退出世界后不得继续。已经种下的植株、已收草药／种子及未拾取掉落保留。任务卡明确区分未完成与完成，`garden_audit` 的通过只代表实际种植／收据核验；不代表未来产量或整片农场可持续。回归普通采矿、砍树、箱子存取、合成链、克眼准备和提醒。

## 0.10.24 低血量自动治疗

本节留给玩家执行；本轮仅自动化与隔离打包，没有进入世界、运行图形客户端、实际喝药或安装个人模组。

1. **设置与触发**：断开模型，核对中英文“低血量自动使用治疗药水”默认开，以及30%默认阈值、10%–50%范围。主背包放未收藏的原版治疗药水，同伴在场，分别试31%、30%及自定义阈值，生命上限应使用饰品／模组修正后的值。关闭自动治疗应不耗药，关闭提醒不应关闭治疗，关闭低血量提醒也不影响治疗。死亡／幽灵、同伴不在、游戏／建造预览暂停时不喝。
2. **选药与节省**：100上限、30当前生命，同时带50／100回血药应优先小药；只有100回血药时，缺79点不喝、缺80点可喝。仅有200回血大药时，15%或以下可应急，16%且药效利用不足时等待。药效以实际 `GetHealLife` 修正值为准。收藏药水、奇异药、蜂蜜、食物、增益药、纯蓝药、生命水晶、未知模组药不自动用；仅虚空袋／箱子有药时也不取。核对没交换背包格、没改变选中手持物和收藏标记。
3. **原生冷却与使用钩子**：普通药水、恢复药水、哲学石／神话护身符及所装模组冷却调整分别验证。已在冷却时持续掉血不喝；原生冷却归零且仍低血时才可再用。不应重置 `potionDelay` 或移除药水疾病，饰品／模组保留消耗的效果应保留。石化、诅咒或物品禁用时不喝；月噬等本来仍可喝药的状态不应被误判禁用。冷却被模组取消时，连续低血一轮只用一次，实际恢复到阈值＋15个百分点后才重新计次。
4. **实际收据与异常**：检查聊天和原生回血效果，提示只能写实际回血／实际消耗，不能把名义回血量照搬为实际增益。治疗已把生命抬高时不发旧低血提示；治疗后仍低血不连续重复警告。背包正在变化、手动喝药同时发生、药水移走、设置改变或原生拒绝时不能错误消耗。特殊模组导致消耗却不回血、多瓶消耗或用药异常时，应该提示并暂停本轮自动治疗，不能连喝；开关来回切换不清异常保护。
5. **作用域与回归**：自动喝药之后，手动H、普通物品使用、其他物品／角色的使用钩子应正常；有异常时临时选药过滤也必须释放。聊天窗口关闭、施工时治疗提示可见，不强开窗口、不切任务。退出／换世界／换角色不串治疗状态；暂停不推进重试节奏。种植、采集、合成链、克眼准备和提醒仍工作；任务需要保留治疗药水时核对真实库存，缺药应如实提示。学习日志 `companion_healing` 记录实际调用、回血、消耗、冷却和异常，不把未生效调用标成治疗成功。

## 如何看证据

```sh
python3 scripts/report_learning.py '<上面的世界目录>/learning.jsonl' --output .runtime/playtest-report.json
```

报告里 `model_asked_when_required` 是模型主动选择；`forced_ask` 是它漏问、代码补拦；`unnecessary_ask` 检查不必询问时是否仍问。需要结合 `proposal_action_types` 看它是否正确做事，不能把一律拒绝或只聊天算成功。

`verified_target_removals` 仅证明执行器实际移除了所提议的原始目标方块；还需核对目标是否就是玩家要求的。`task_success_rate=null` 表示没有独立目标判定，不是零分或满分。当前没有自动训练、技能演化或 LoRA。

真实模型无界面测试覆盖静止、近距离的对话与采集控制；离线引擎检查另覆盖等待锚点、跟随切换、任务卡状态与取消竞态。它们未测试实际绘制和完整地形物理。此验收还需观察跟随、跳跃、不同地形、游戏帧率和 CPU 推理并行时的体验，并记录失败发生在理解、规划、等待还是实际执行阶段。

## 0.10.25 作弊世界操作

以下为玩家待执行的实机验收，本轮仅跑自动化，没有进入世界或替换个人Mods。

1. **统一开关**：断开模型，在开关关闭时分别试“时间改成21:00”“天气改成下雨”“召唤克眼”“把世界出生点设在这里”；世界不变化。开启后这些句式无需模型即可执行。物品／存好的建筑仍受同一开关控制；关闭、退世界、换世界后均不能执行。让一个模型作弊请求等待响应，开关关后再开，旧响应不得生成东西，重新发令才有效。多人、死亡、幽灵、暂停或施工预览暂停时均拒绝修改。
2. **时间与天气**：分别检查04:29／04:30、19:29／19:30、00:00和23:59，核对钟表、昼夜、日晷／月晷加速被停止。跨日夜应按原生切换处理月相、血月等事件；同一时段倒拨不应补跑整天。24:00、12:60或复合句不能执行。下雨／晴天核对原生降雨、雨量、持续时间和提示；停雨保留风速、沙尘暴和血月事件，天气锁定模组可能覆盖后续状态。
3. **Boss**：测试世界中单独验收18种原版Boss。克眼、骷髅王、双子和机械Boss白天应提示先调夜晚；世吞／克脑分别需腐化／猩红，蜂王需丛林，巨鹿需雪原，肉山需地狱，史莱姆皇后需神圣，世花需地下丛林，石巨人需神庙，猪鲨需海边。核对原生特殊入口需要的祭坛／空间与拒绝提示，双子应两只都生成；任一Boss已在场时再召唤应拒绝。NPC空位不足应拒绝；若模组拦截造成部分生成，报告真实主体数且不自动重试。核对后续阶段、目标、AI、消失、掉落和原生事件行为，不仅看生成提示。作弊不直接写击败进度，真实击杀仍按游戏处理。
4. **误触发与命名**：测试“怎么召唤克眼”“不要召唤克眼”“帮我准备打克眼”、旧对话、未知／模组Boss、NPC编号、两个克眼及复合指令。不得召唤或顺便改时间；夜晚和召唤需分别发令。光之女皇白天应给出危险提示。常用简称和英文原名只精确对应名单，不做模糊匹配。
5. **世界出生点**：站在三格平地、四格净空处设置，核对报告的脚下格坐标及世界地图出生点。平台、斜坡、半砖、空中、世界边缘、积水／岩浆、陷阱／电线／落沙处应拒绝，不清地形、不传送。正常保存退出后重进，作弊仍关闭，世界出生点应保留。无床角色死亡／回忆、另一角色入世界应使用原生世界默认出生点；有有效床绑定的角色仍优先回床，个人绑定不被改变。测试之后改造附近地形时，原生重生仍可能寻找安全位置，不能保证永远固定原坐标。
6. **日志与回归**：`cheat_world` 记录请求动作／值、成功标记和实际即时结果；失败不能记录成成功。原有生成物品、StructureHelper建筑、查找床、合成／施工、护卫、提醒和自动治疗仍可用；时间变化后的采草条件、天黑提醒和药水冷却按真实状态运行。
## 0.10.28 协作任务（待玩家实机验收）

1. 说「一起准备打克眼」「药水我来」「继续协作」。核对场地材料单没有药水；拒绝时无消耗。确认后完成场地，再说「继续协作」，核对仍需玩家实际备齐药水，口头说完成不能通过。
2. 说「协作扩建2间NPC住房」「备料你来」「继续协作」。核对背包／箱子取料及合成链原确认；备料后说「住房我来」「继续协作」，选址后游戏应恢复运行，原施工按钮禁用。自行建完后「核验协作」，两间均需通过入住检测。
3. 施工途中「住房你来」交接，或「暂停协作」后「继续协作」：复用原位置和已完成格子，旧按钮／模型回复不能执行；新预览必须确认。缺料时只补剩余格子，原偏好与采集询问仍生效。
4. 选址前「住房改成三间」必须重新计算并撤销旧确认；选址后拒绝改数量扩大范围。石土、已有家具、电线／液体等障碍不能被协作住房自动拆除。住房蓝图放完但原生检测不合格不得报成功。
5. 途中移走制作站／材料，检查失败原因、进度和新库存，以及恢复的新确认；未知异常不自动重试。完成阶段后消耗药水或破坏住房，再「核验协作」应拒绝最终完成。
6. 拒绝、stop、死亡、换世界、替换同伴后不能复活旧任务。退出重进不恢复运行计划；普通非协作克眼准备、建造、修补、合成与作弊开关继续回归测试。
