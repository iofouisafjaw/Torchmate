# 确认后开路采矿 · 0.10.33

## 使用方式

先让同伴站在你12格内的干燥稳定地面，背包带镐。说“规划通道挖铁矿”“规划通道挖矿”或“挖过去采矿”。
预览包含矿种、坐标、每段中心/脚底坐标、三格宽四格高范围和最大移除数。说“同意”或点击同意才施工。
每次锁定一个矿格；不自动扩挖整条矿脉。普通计数采矿找不到露头矿时会提示此入口。

每次规划最多检查8个候选矿，每条搜索最多512个状态。横向限制28格、深度12格、最多40段/128块；未找到方案就拒绝。
默认先清理每段，再用现有碰撞寻路到落脚点，核对返回入口的路线，最后采目标矿格。完成后原地等待。
移除数有直接方块收据；掉落是否入包由背包另行核对，满包不会丢弃剩余掉落。

## 复用及权限

复用竖井任务的持有者、确认按钮、控制版本、暂停/停止和失败恢复；复用并提取竖井原有 DiggingSafety 检查，
施工调用 MineAction(singleTile, inventoryToolsOnly, guard)；移动调用 MovementHelper/TerrainRoute，不走作弊传送。
规划器不能授权；确认绑定世界、任务、整个计划、规则版本、昼夜和两分钟有效期。新预览不能复用旧确认。

预览无世界修改。确认前重查完整快照及起点；执行时每格重查计划范围、类型、镐、权限、周围条件和距离。
任何液体、落沙/滚石/陷阱、电线、家具、可住房墙、漆或制动器会阻止对应范围施工。
移动失败、下一落脚点无支撑、返回路线不可核实、附近出现敌怪、超时或10秒无进展会停止，保留部分工程与原因。
停止、等待、召回、新指令、离开世界、角色失效会取消。失败恢复沿用 expedition 回执，不会自动扩大计划或代玩家确认。
此检查覆盖已识别地形及危险，不保证检测所有模组机制；不能把规划成功当成实机安全证明。

## 玩家验收

1. **预览不动工**：用“规划通道挖铁矿”，等一会儿。应显示矿种、路线、范围、数量，地形和背包不变。
2. **确认施工**：在普通泥土/石头附近、深度约3–8格放/找一格埋藏矿；同意后应逐段清理、行进，最后核实矿格移除。
   左右两个方向都测，结束后让同伴跟随回到入口，确认台阶可返回。
3. **撤销**：未确认时取消；施工几块后分别测试停止、等待、召回。不能再挖，部分工程保留。
4. **地形变化**：预览后在计划附近加液体或电线，再同意；应拒绝并要求重新规划。施工中变化也应停，失败信息与实际移除量一致。
5. **授权变化**：旧预览被新预览替换、昼夜/规则变化、确认过期、角色移动或镐被拿走后，旧确认不能动工。
6. **危险/边界**：带液体、落沙、建筑/箱子、电路、没有支撑、超深或镐力不足的候选应拒绝，不能为了完成扩大开挖范围。
7. **常规回归**：旧的露头采矿、水坑跟随、竖井和普通探路仍按原流程工作。
