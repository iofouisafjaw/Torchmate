Torchmate (小火伴) 0.10.34 — Windows single-player source Alpha. Internal mod ID: TerrarAI.
On-device Qwen3 / llama.cpp companion with an observe-decide-execute-verify loop, state-constrained JSON Schema, optional local Wiki RAG, and permission-checked failure recovery. Gathering, chest logistics, crafting chains, building, housing checks, protection, maps, gardening, healing and cooperative Eye/housing tasks reuse deterministic planners.
Resource-changing long tasks require preview and confirmation; recovery preserves verified progress, refreshes resources and requires new approval for a new plan. No cloud API is required for inference. Model weights, inference runtimes, game files and Wiki databases are not bundled. Source users need Python 3.11+ x64 and .NET 8 to build.
