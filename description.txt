TerrarAI 0.10.30 — Windows Alpha preparation, single player.
Local Qwen3 / llama.cpp companion with gathering, chest logistics, crafting chains, building, housing inspection, protection, maps, gardening, healing and cooperative Eye/housing tasks. Resource-changing work keeps its original confirmation and permission checks; failures return verified progress and current resources.
Requires a separate local model service; no cloud API is required for inference. The qwen3-4b API alias is historical; the selected model can be 14B or experimental 8B. Model weights, inference runtimes and Wiki databases are not bundled. The current kit requires Python 3.11+ x64. Gameplay and clean Windows acceptance remain pending.
Active inherited implementations and icons were removed/replaced in 0.10.30; historical versions are not authorized by that work. Project-wide licensing remains undecided.
